# Doggo

Doggo är en responsiv webbplats för hundägare där användaren kan hitta aktiviteter, läsa tips och inspiration samt upptäcka hundvänliga platser.

Projektet är utvecklat som en del av kursen **Responsiv webbdesign** med fokus på semantisk HTML5, modern CSS, tillgänglighet och användbarhet.

---

## Live Demo

https://doggocommunity-html-css.netlify.app/

---

## Syfte

Syftet med projektet var att utveckla en responsiv webbplats av hög kvalitet där användaren enkelt kan navigera mellan olika sidor och ta del av relevant information oavsett vilken enhet som används.

Projektet har utvecklats enligt **mobile first** där designen först anpassades för mobil och därefter byggdes ut för surfplatta och desktop med hjälp av media queries.

## Responsiv design

Webbplatsen är utvecklad enligt Mobile First och fungerar i flera olika skärmstorlekar.

Breakpoints:

- Mobil
- Surfplatta (768px)
- Desktop (1024px)

Layouten använder Flexbox och CSS Grid beroende på innehåll och skärmstorlek.
